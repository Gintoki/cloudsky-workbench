# 核心研究框架

所有公司使用下列核心章节：投资结论、公司画像、能力圈与可预测性、核心假设、行业与竞争、护城河、管理层与治理、财务质量、盈利质量与资本回报、估值、催化剂与风险、监控指标、来源与版本。

护城河按品牌与无形资产、切换成本、网络效应、成本/规模优势、数据与生态、渠道、牌照政策、技术、客户关系逐项记录强度、趋势、证据、反证、可持续期与失效条件。技术领先要注明其是暂时、依赖持续投入，还是结构性优势。

财务指标至少覆盖收入、毛利率、营业/净利率、ROE、ROIC、经营/自由现金流、现金转换、负债、净现金/净负债、资本开支、营运资本、稀释、研发和销售管理费用。报告值、正常化值和异常解释必须分开。

估值不是质量评分。可选 PE、PS、EV/EBITDA、DCF、所有者盈余、分部、可比、重置成本、正常化利润和情景估值；只选择适合公司经济特征的方法。
