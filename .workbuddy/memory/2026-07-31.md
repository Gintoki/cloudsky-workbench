## 本地启动成功（Supabase + Session Pooler）

**环境探针**：
- Node v22.22.2 ✅（要求 ≥22.13）/ npm 依赖装齐 543 包（含 `vinext` 0.0.50）
- Docker 未装、本机无 PostgreSQL 服务、5432 无监听 → 走云 PG

**选型**：Supabase Free（项目 ref `yrhuhzzmtdmzlmkibkoj`，region ap-northeast-2 首尔）

**踩坑（重要，下次必看）**：
- Supabase Free 的 **Direct connection（`db.[ref].supabase.co`）只给 IPv6**，本机/沙箱无 IPv6 公网 → `ENOTFOUND`
- drizzle-kit migrate 在 DNS 失败时会**静默退出**（spinner 转完无报错），导致误以为迁移成功，实际 public 表数量 = 0
- **必须用 Session pooler**：`aws-1-ap-northeast-2.pooler.supabase.com:5432`（IPv4），用户名带 `.project-ref` 后缀
- Transaction pooler（6543）不选：Drizzle + `postgres` 驱动用 prepared query，Session pooler 兼容性更好

**最终 .env DATABASE_URL**：
`postgresql://postgres.yrhuhzzmtdmzlmkibkoj:[PWD]@aws-1-ap-northeast-2.pooler.supabase.com:5432/postgres`
